# GPT image prompts: city tiles and concert figurines (v3.3)

Two sets: **A. the city** ("Every route, in every size") and **B. the concert** ("One brief. A route for every kind of buyer"). Each set has one style block and a list of one-line assets.

## How to use (both sets)

1. Start a fresh ChatGPT chat for each set. Paste the **style block** first and wait for "ready". Then send one asset line per message, so you get one image per asset.
2. End every asset line with: *"PNG, fully transparent background, nothing else in the frame."* If a backdrop sneaks in, reply "remove the background, transparent PNG".
3. Stay in the same chat for the whole set so the angle, light and palette match. If one drifts, reply "match the camera, light and scale of the first image exactly".
4. Save each image under the file name given into `~/claude/dev/dazbee/landing/public/sprites/city/` or `.../sprites/concert/`, and tell me. I'll place and tile them in code: ground tiles snap to the grid, and objects stand on it, sorted back to front.
