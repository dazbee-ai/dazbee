# Dazbee landing page (v3.5)

One-page site built with Vite and GSAP.

    cd landing
    npm install
    npm run dev

Then open the address it prints (usually http://localhost:5173). Draft 1 is in `versions/v1/`, v2 in `versions/v2-archive/`, the references in `moodboard/`. See `CLAUDE.md` for structure, stack and rules, and `content/` for the copy.
